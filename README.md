# CRM Standfit — demo

Este repositorio contiene **solamente la version publicada del CRM** de Standfit,
para poder abrirlo en GitHub Pages.

- **App:** https://coletti68.github.io/CRM-Standfit-Pages/

## Que se puede ver

Es una **demo con datos ficticios**, sin informacion real de clientes ni precios:

- Panel con los indicadores del area comercial.
- Kanban de leads en dos embudos (Leads y Clientes), con arrastre entre etapas.
- Conversaciones de WhatsApp simuladas, con el agente de IA respondiendo.
- Bandeja con todos los chats.

## De donde sale

El codigo fuente **no es publico**. Vive en el repositorio privado del proyecto
y este repo se genera automaticamente a partir de el con `npm run build:pages`.

Los nombres, telefonos y conversaciones son ficticios. Los precios que muestra el
agente son de ejemplo y **no reflejan la lista real**: sirven unicamente para
mostrar como funcionaria el sistema.
